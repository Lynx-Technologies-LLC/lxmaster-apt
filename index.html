LXMASTER apt repository

Real-time EtherCAT master — latest release: v1.2.4

Install

curl -fsSL https://lxmaster.apt.lynxtechs.com/lxmaster.gpg | sudo tee /usr/share/keyrings/lxmaster.gpg >/dev/null

SUPPORTED="jammy noble resolute bookworm"
CODENAME="$(lsb_release -cs 2>/dev/null || echo unknown)"
case " $SUPPORTED " in
  *" $CODENAME "*) ;;
  *) echo "lxmaster does not publish packages for '$CODENAME'. Supported: $SUPPORTED. Build from source instead." >&2; exit 1 ;;
esac

echo "deb [signed-by=/usr/share/keyrings/lxmaster.gpg] https://lxmaster.apt.lynxtechs.com $CODENAME main" | sudo tee /etc/apt/sources.list.d/lxmaster.list
sudo apt update && sudo apt install lxmaster

The codename check fails clearly and immediately on an unsupported system, instead of falling through to a confusing apt dependency error partway into the install.
